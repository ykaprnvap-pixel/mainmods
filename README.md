# Terraria Lite (Android)

Прототип 2D sandbox-игры «по типу Terraria» для Android на Kotlin.

## Что реализовано

- процедурно сгенерированный 2D мир из блоков (трава/земля/камень);
- базовая физика игрока (движение, гравитация, прыжок, коллизии);
- камера, следующая за игроком;
- разрушение и установка блоков касанием;
- простое touch-управление:
  - нижний левый сектор — идти влево;
  - нижний правый сектор — идти вправо;
  - нижний центр — прыжок;
  - верхняя область — ломать/ставить блоки.

## Структура

- `MainActivity` — запуск игры;
- `SandboxGameView` — игровой цикл, рендер, ввод;
- `GameWorld` — тайловый мир и операции с блоками;
- `Player` — состояние персонажа и физика.

## Запуск

1. Открой проект в Android Studio (JDK 17).
2. Синхронизируй Gradle.
3. Запусти `app` на эмуляторе или устройстве Android.

## Ограничения текущего прототипа

- нет крафта, инвентаря, мобов и биомов;
- нет сохранений мира;
- используется примитивная отрисовка `Canvas` (без оптимизаций).

Если хочешь, следующим шагом могу добавить:
1) инвентарь + хотбар,
2) генерацию пещер,
3) простых мобов,
4) сохранение мира в файл.
