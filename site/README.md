# Moped24 — обновлённая версия сайта

Статический сайт мотосалона: чистый HTML, CSS и ванильный JavaScript.
Сборки нет — файлы можно выложить на любой хостинг как есть.

## Запуск локально

Каталог загружает данные через `fetch`, поэтому страницам `catalog/` и `catalog/product.html`
нужен http-сервер (при открытии по `file://` браузер блокирует запрос):

```bash
cd site
python3 -m http.server 8080
# затем открыть http://localhost:8080/
```

Остальные страницы (главная в части текстов, «О магазине», «Доставка», «Рассрочка», «Контакты»)
работают и без сервера.

## Структура

```
index.html                 главная
catalog/index.html         каталог: фильтры, сортировка, поиск
catalog/product.html       карточка товара, рендер по ?id=
about/index.html           о магазине
about/delivery.html        доставка и оплата
about/installment.html     рассрочка и кредит
about/contacts.html        контакты и схема проезда
assets/css/style.css       вся дизайн-система и компоненты
assets/js/site.js          меню, FAQ, формы, загрузка каталога, карточки
assets/js/catalog.js       фильтрация, сортировка, состояние в URL
assets/js/product.js       страница товара и похожие модели
assets/data/products.json  данные каталога
assets/img/*.svg           логотип и иллюстрации
robots.txt, sitemap.xml    для поисковых систем
```

Общие шапка и подвал скопированы в каждую страницу (сборщика нет) — при правке
меню или контактов пройдитесь по всем семи HTML-файлам.

## Данные каталога

`assets/data/products.json` — единственный источник данных для каталога, карточек и плиток категорий.

```jsonc
{
  "categories": [
    { "id": "moto", "title": "Мотоциклы", "image": "moto.svg", "description": "…" }
  ],
  "products": [
    {
      "id": "moto-cruiser-250",     // используется в ссылке catalog/product.html?id=…
      "name": "Дорожный мотоцикл Cruiser 250",
      "category": "moto",           // id из categories
      "price": 289000,              // число, рубли
      "oldPrice": 315000,           // null, если скидки нет
      "inStock": true,              // бейдж «В наличии» / «Под заказ»
      "hit": true,                  // попадает в блок «Популярные модели»
      "engineCc": 250,              // null для экипировки и запчастей
      "image": "moto.svg",          // файл из assets/img/
      "summary": "Короткое описание для карточки",
      "specs": { "Двигатель": "…", "Мощность": "…" }   // произвольные пары для таблицы
    }
  ]
}
```

## Что заменить на реальные данные

1. **Каталог.** Позиции, цены и характеристики в `products.json` — демонстрационные.
   Замените их выгрузкой магазина (формат выше).
2. **Фотографии.** Вместо `assets/img/*.svg` подставьте реальные фото техники
   (одинаковая пропорция, лучше 4:3, с прозрачным или светлым фоном) и обновите поля `image`.
   Для соцсетей замените `og:image` в `<head>` каждой страницы на растровое изображение 1200×630.
3. **Формы.** Заявки сейчас не уходят на сервер: скрипт валидирует поля и формирует письмо
   на `info@moped24.ru` (обработчик `initForms` в `assets/js/site.js`).
   Для интеграции с CRM замените блок формирования `mailto:` на `fetch('/api/lead', …)`.
4. **Реквизиты.** В подвал стоит добавить юридические данные продавца — в этой версии их нет,
   чтобы не публиковать непроверенные сведения.
5. **Карта.** На странице контактов нарисована схема-ориентир (SVG) и стоит ссылка на 2ГИС.
   При желании подключите интерактивную карту — учтите, что это добавит сторонние скрипты.

## Данные о компании в разметке

Адрес, телефоны, режим работы и e-mail продублированы в JSON-LD (`MotorcycleDealer`) на главной
и в хлебных крошках (`BreadcrumbList`) на внутренних страницах. При изменении контактов
поправьте и видимый текст, и JSON-LD.

## Доступность и производительность

Внешних шрифтов, аналитики и CDN нет. Поддержаны светлая и тёмная схемы (`prefers-color-scheme`),
`prefers-reduced-motion`, клавиатурная навигация, skip-link и aria-состояния меню, аккордеона и фильтров.
